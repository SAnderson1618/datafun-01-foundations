# Colorado Tornado Analysis

This project analyzes historical tornado records from the NOAA Storm Prediction Center (1950-2022).

Our analysis specifically focused on isolating records for the state of Colorado. Using Python and Pandas, we discovered a total of 2,337 historical tornadoes in Colorado during this period. The data reveals that the vast majority of these were lower-level storms, with the most common magnitude being EF-0 (1,527 occurrences).
